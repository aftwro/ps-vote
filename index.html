Tutorial · Pack Setup
What to do
01
Join the server
Connect to play.lunarlabs.fun in Minecraft Java Edition.
02
Accept the resource pack prompt
A dialog will appear asking you to download the server resource pack. Click Yes to accept and download it.
03
Set pack to always download
To skip the prompt next time, open Options → Server Resource Packs and set it to Enabled. The video above shows exactly where this is.
04
Rejoin and enjoy
Once the pack loads you'll see custom textures, UI elements, and items. If anything looks broken, try F3 + T to reload resource packs.
Having trouble? Make sure you're not using any pack blocking mods, If the pack keeps failing, ask a staff member in our Discord at discord.gg/lunarlabsmc
